# UTS-IAE-RENTALPS - API Documentation

## Overview

This repository contains the **API documentation** for the **UTS-IAE-RENTALPS** project. The API provides functionalities for managing the rental system of game consoles. The documentation is structured using **Postman** collections, which include various requests for interacting with the service.

The API allows you to:

- View available consoles.
- Create and manage user orders.
- Retrieve order information.
